# 📄 Submit-a-resume - 智能岗位匹配助手 v6.0

> 一个专为**智联招聘 / Boss直聘 / 前程无忧 / 猎聘**设计的 Tampermonkey 油猴脚本，自动计算岗位与你的技能匹配度，**一键投递 + 批量投递 + 黑名单/红旗关键词过滤 + 经验筛选 + 每日限额 + 投递统计图表 + 断点续投**，快速找到适合你的工作。配套本地**管理后台**（`backend/` 目录）可以集中查看统计图表、管理投递记录、调整投递策略。

## 🆕 v6.0 更新

- **本地管理后台**（`backend/` 目录）：Node.js + Express + JSON 文件存储，零数据库依赖
  - 📊 总览：累计/今日投递数、平均匹配度、近14天趋势图、平台分布、高频技能
  - 📋 投递记录：搜索/筛选/删除/导出 CSV
  - ⚙️ 投递策略：城市、关键词、黑名单、薪资、经验等可在网页上直接改
- 脚本设置面板新增「同步到后台」开关，投递成功后自动把记录推送到本地后台（默认关闭，不影响原有本地存储）
- 面板右上角新增 🌐 图标，一键打开管理后台页面

## v5.1 修复

- **修复去重 bug**：原来只按岗位名称去重，不同公司发布同名岗位时第二家会被误跳过；现在按"岗位名+公司名"联合去重
- 经验年限解析更精确：优先在"经验"关键词附近取文本再解析，减少被无关数字误命中

## v5.0 更新

- **多平台支持**：新增前程无忧、猎聘（选择器为常见结构的最佳猜测，如遇改版失效请按 F12 检查实际 class 名后在脚本内 `SITE_CONFIGS` 里调整）
- **经验要求过滤**：自动解析岗位"经验不限/3-5年/5年以上"等描述，超出你可接受范围自动跳过
- **红旗关键词过滤**：命中"日结""押金""培训费"等风险描述自动跳过，减少踩坑
- **优先级排序投递**：同一页内先算出所有岗位匹配度，按分数从高到低排序后再投递
- **📊 投递统计图表**：近14天投递趋势柱状图 + 高频匹配技能 Top10
- **断点续投**：如果投递中途刷新/中断页面，10分钟内可一键"继续"上次未完成的批次
- **打招呼语模板**（Boss直聘）：自动填入聊天框（不自动发送，发送前你可以先检查确认）
- **节奏更平稳**：投递/翻页间隔加入随机浮动（jitter），降低连续固定节奏造成的页面卡顿或误触发
- **看门狗**：若运行较长时间仍 0 投递成功（通常是选择器与页面不匹配），自动停止并提示，而不是无意义空跑

> 说明：本脚本只做"更贴近真实使用节奏、更少出错"的稳定性优化，不包含任何用于规避平台反作弊/风控检测机制的功能。

## 📦 安装方法

### 1. 安装油猴插件
| 浏览器 | 插件地址 |
|--------|----------|
| Chrome | [Tampermonkey](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) |
| Edge | [Tampermonkey](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd) |
| Firefox | [Tampermonkey](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/) |

### 2. 安装脚本
- 点击 `zhaopin_job_helper.user.js` 文件
- 点击右上角 **Raw** 按钮
- Tampermonkey 会自动弹出安装提示 → 点击 **安装**

### 3. 使用
- 打开 [智联招聘](https://www.zhaopin.com/) 或 [Boss直聘](https://www.zhipin.com/) 搜索任意岗位
- 页面右侧出现 **🤖 自动投递** 面板
- 每个岗位卡片自动显示匹配度评分
- 点击面板右上角 **⚙️** 打开设置，调整城市、关键词、黑名单、薪资、每日限额、技能库等

## ⚙️ 设置面板说明（v4.0 新增，无需改代码）

打开脚本运行后，点击面板右上角的 ⚙️ 图标即可看到：

- **目标城市** / **岗位关键词**：逗号分隔，支持多个
- **黑名单关键词 / 黑名单公司**：命中即自动跳过该岗位（例如过滤"外包""劳务派遣"）
- **期望薪资范围**：岗位薪资区间与期望区间有重叠即视为合适；可勾选是否跳过"面议"岗位
- **投递数量**：单轮目标 / 每日上限 / 投递间隔(ms)
- **开关项**：自动翻页、失败重试、提示音、桌面通知
- **技能库**：JSON 格式，可自定义技能权重(`weight`)和分类(`category`)，用于匹配度评分和分类统计

所有设置保存后立即生效，并持久化保存在浏览器本地（`GM_setValue`），下次打开无需重新填写。

如果你更喜欢直接改代码，脚本顶部的 `DEFAULT_CONFIG` 仍然可以作为初始默认值编辑：

```javascript
const DEFAULT_CONFIG = {
    city: '佛山',
    jobKeywords: ['IT技术支持', '运维工程师', ...],
    blacklistKeywords: ['外包', '劳务派遣', '中介'],
    expectedSalary: [7000, 10000],
    dailyLimit: 30,
    skills: {
        'Python': { weight: 8, category: '开发' },
        // ...
    },
};
```

## 📁 项目结构

```
job-helper/
  script/
    zhaopin_job_helper.user.js   # 油猴脚本（安装到浏览器）
  backend/
    server.js                     # 管理后台服务，node server.js 启动
    src/                          # 后端逻辑（数据存储、API 路由）
    public/                       # 管理后台网页（总览/记录/策略配置）
    README.md                     # 后台单独的启动说明
  README.md                       # 本文件
```

管理后台是可选组件：不启动它，脚本本身的自动投递、匹配度评分、黑名单过滤等功能完全不受影响，只是没有集中的网页统计面板。启动方法见 [backend/README.md](backend/README.md)。

## ⚠️ 使用须知

- 请遵守各招聘平台的用户协议，合理设置每日投递数量，避免账号被限制。
- 自动投递不能替代针对性投递，建议对高匹配度、真正感兴趣的岗位手动确认后再投递。
- 黑名单和薪资过滤基于页面文本关键词匹配，无法保证 100% 准确，建议投递前用筛选功能人工复核。
